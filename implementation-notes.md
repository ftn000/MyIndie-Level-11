# Implementation notes

- **Стек:** один `index.html`, Canvas 2D + WebAudio, без зависимостей. Выбрано ради геймджема: открывается двойным кликом, легко залить на itch.io или Яндекс Игры. Если нужен другой движок, мир и механики перенесутся: уровень собирается кодом (`build()`), не файлом.
- **Свет:** мир рисуется на основном canvas, поверх идёт тёмная маска (`lc`) с вырезанными радиальными градиентами вокруг источников. Тёплая аддитивная подсветка перед маской даёт «оживление цветов».
- **Формулы:** расход `0.012 + 0.04·s` в секунду (большое горит ~2.7× быстрее), радиус света `50 + 270·s`, прыжок `350 + 130·s`, рывок −0.15, свеча +0.5, бумага +0.3, у свечи +0.25/с без расхода.
- **Хитбокс** растёт с размером. Решётка `v` не пускает при `s ≥ 0.3`.
- **Не сделано (вырезано под джем):** ночные хищники-тени, воск, парашют вне потоков, музыка (есть ambient-пэд и шумовой треск).
- **Тест:** `window.game.step(dt)` для детерминированного прогона без реального времени (в скрытой вкладке rAF троттлится). Бот прошёл пропасть; лёд, решётка, мост и камин проверены скриптом. На слух и на ощущение управления не проверял.

## Unity (решение от 2026-11-13)

- **Дедлайн джема: 2026-11-15 22:00.** Один программист, арт генерирует команда.
- **Стек:** Unity 6000.3.11f1, URP 3D, проект в `Unity/`. Cinemachine 3, Input System, ProBuilder. Платформа WebGL (сайт джема).
- **Подход:** 2.5D. Мир 3D, движение по плоскости X/Y, Z зафиксирован. Огонёк это billboard-спрайт (рисованный, от команды) + ParticleSystem + настоящий `Point Light` с радиусом от `Size`. Тени только у света огонька (WebGL).
- **Контроллер:** свой кинематический на `BoxCast`, числа из веб-прототипа (расход `0.012+0.04·s`, прыжок `350+130·s` px/s → переводим в м/с при 1 тайл = 1 м).
- **Скоуп под 2 дня:** вертикальный срез из 3 секций (старт и свечи, капли и лёд, верёвка и мост + камин). Тёплые потоки, сквозняк и решётка только если останется время.
- **Git:** секции уровня отдельными сценами (additive), одну сцену правит один человек.
- **Статус Unity (2026-11-13):** есть весь веб-уровень в 3D: `Flame` (топливо/свет), кинематический контроллер, свечи, бумага, капли, лужи, лёд, верёвки с мостом, решётка, сквозняк, тёплые потоки, камин. Сцена собирается editor-скриптом `OgonokBuilder`. Точечный свет с тенями только у огонька. PlayMode-тесты проходят 5 из 5 (лёд, решётка, мост+камин, пропасть ботом, формула расхода). Заглушки: спрайт огонька (капля), материалы, декор (цветные кубы). Звука нет.
- **Грабли:** (1) в `manifest.json` обязательны `com.unity.modules.*`, иначе нет ParticleSystem; (2) `Set-Content -Encoding utf8` в PS 5.1 пишет BOM, Unity считает манифест невалидным; (3) `Shader.Find` в рантайме для WebGL нельзя, материалы ссылаются на шейдеры из ассетов.
