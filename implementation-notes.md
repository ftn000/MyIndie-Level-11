# Implementation notes

- **Стек:** один `index.html`, Canvas 2D + WebAudio, без зависимостей. Выбрано ради геймджема: открывается двойным кликом, легко залить на itch.io или Яндекс Игры. Если нужен другой движок, мир и механики перенесутся: уровень собирается кодом (`build()`), не файлом.
- **Свет:** мир рисуется на основном canvas, поверх идёт тёмная маска (`lc`) с вырезанными радиальными градиентами вокруг источников. Тёплая аддитивная подсветка перед маской даёт «оживление цветов».
- **Формулы:** расход `0.012 + 0.04·s` в секунду (большое горит ~2.7× быстрее), радиус света `50 + 270·s`, прыжок `350 + 130·s`, рывок −0.15, свеча +0.5, бумага +0.3, у свечи +0.25/с без расхода.
- **Хитбокс** растёт с размером. Решётка `v` не пускает при `s ≥ 0.3`.
- **Не сделано (вырезано под джем):** ночные хищники-тени, воск, парашют вне потоков, музыка (есть ambient-пэд и шумовой треск).
- **Тест:** `window.game.step(dt)` для детерминированного прогона без реального времени (в скрытой вкладке rAF троттлится). Бот прошёл пропасть; лёд, решётка, мост и камин проверены скриптом. На слух и на ощущение управления не проверял.
