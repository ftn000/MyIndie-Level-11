# Текстуры грейбокса Wisp

16 сгенерированных Base Color / Albedo, T01–T16. Все PNG: 1254×1254 px. Изображения скопированы из встроенного image_gen без ресайза и ретуши.

## Состав

- `*-basecolor-v1.png`: изображения материалов.
- `*-basecolor-v1-prompt.txt`: промпты рядом с результатами; у T01 точный запрос указан в metadata как `T01-user-prompt.txt`, соседний prompt сохраняет первоначальный текст каталога.
- `*-user-prompt.txt` и `T01-user-prompt.txt`: точные отправленные запросы.
- `*-metadata.json`: размеры, SHA-256 и статусы проверок.
- `R01-seams-repair-prompt.txt` / `R02-contrast-repair-prompt.txt`: исправление швов и снижение контраста; прикрепляется выбранная текстура.

## Подключение

1. Проверяем бесшовность T01/T03/T04/T06 повторением 3×3 до массового назначения. Слово seamless в запросе не гарантирует бесшовность результата.
2. Импортируем выбранные PNG как Base Color: Default / 2D, sRGB включён, Wrap Mode Repeat, mipmaps включены; фильтрацию и компрессию проверяем по кадру в движении и целевому WebGL.
3. Пробуем URP/Lit на коротком участке, выравниваем масштаб рисунка и учитываем затемнение существующим material tint. Не растягиваем одну доску на всю длину пола.
4. Сохраняем mesh, transforms, collider, проёмы, свет, маршрут и механику существующего грейбокса.
5. Закрепляем назначения в общем пути сборки: OgonokBuilder пересоздаёт материалы. Глобальный Stone используется разными зонами, поэтому дерево дома нельзя назначать заменой всем Stone.
6. Проверяем настоящие кадры до/после при одинаковой камере и свете, затем распространяем материалы по зонам.

Дом: дерево, штукатурка, кирпич, ткань. Подвал/канализация/шахта: общие кладка и металл, дерево плотов/ящиков. Лес/костёр: кора, снег, лёд, природный камень. T12–T15 используем только при видимой пользе. Вода, огонь, метан, пар, смола и финальное свечение остаются существующими материалами/эффектами.

## Проверено и ограничения

Проверены PNG CRC, распаковка IDAT, размеры, SHA-256 и наличие промптов. Изображения просмотрены при генерации. Бесшовность повторением, UV, импорт Unity и WebGL пока не проверены. Это исходники для интеграции, не готовый проверенный набор Unity-материалов. Normal/height/roughness-карты не создавались. Ночные концепты и визуальные макеты в этот пакет не входят.
