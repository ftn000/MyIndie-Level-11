## МОДЕЛЬ И РЕЖИМ

Работать в текущем проекте штатными средствами Unity, без новых пакетов и middleware. Использовать уже открытый Editor. Сначала тест для нетривиальной логики, затем реализация. Не выполнять commit/push без прямого подтверждения. Этот документ описывает будущую реализацию; наличие файла не означает, что аудио уже подключено.

## ПРАВИЛА ВОСПРОИЗВЕДЕНИЯ

1. Треск Игни плавно менять по форме. Тревожный слой управлять топливом: ниже `Flame.GuttersBelow` (сейчас 0.25), с плавным вводом/выводом. Маленькая форма при полном топливе не звучит умирающей. При смерти выключить обе петли; после респауна восстановить одну копию каждой.
2. Прыжок звучит при реальном толчке в MoveInput, а рывок только после принятия действия по топливу/cooldown. Нажатие невалидной кнопки или прыжок в воздухе не запускают соответствующий звук. Превращение отслеживать по смене выбранной формы, не по каждому изменению плавного `size`.
3. Смерть запускать через `Died`, один раз. Финальный `Surrender()` не вызывает этот звук. Возвращение в финале и обычный респаун имеют разные контексты, не дублировать возрождение и превращение.
4. Передачу огня котлу начать при действительном прогрессе удержания E; при отпускании, удалении или нехватке топлива остановить. Успех запускается через `Given`/Ignite один раз. Если заданное время удержания изменилось, согласовать длину клипа.
5. Предупреждение Fan запускать на входе в фазу предупреждения, порыв на начале Gusting, в пределах слышимости источника и этажа. Не запускать одновременно все окна уровня глобальным 2D-звуком. Штора является дополнительным слоем без второй записи ветра.
6. Каплю, промахнувшуюся мимо Игни, озвучивать только при реальном контакте с водой. Сейчас Drop удаляется также при касании твёрдой поверхности или выходе за мир: не считать каждый Destroy всплеском. Для маленьких капель/снега различать тип источника, а не разбрасывать проверки имени GameObject по коду. Снежный урон озвучивать мягче и с ограничением частоты.
7. Звук льда запускать на разрушении. Звук намерзания запускать при начале видимого роста после ожидания, один раз за восстановление. Не озвучивать каждую итерацию Update и принудительный Restore при респауне.
8. Ограничить одновременно слышимые капли, звенья верёвки, снежинки и плоты, добавить небольшие вариации громкости/тона для повторов, если это не портит тембр. Дубли выбирать из пула явно назначенных клипов. Начальные ограничения выбрать после прослушивания и записать в отчёте.
9. Локальные объекты звучат с затуханием по расстоянию, фон и UI без позиционного панорамирования. Проверить масштаб сцены и XY-плоскость, чтобы близкие объекты не терялись из-за глубины камеры. Петли исчезающих/выключенных объектов останавливать и освобождать.
10. Фоны переключать по реальной текущей зоне, включая ZoneExit, отладочный JumpToZone и респаун. Не угадывать зону только по X: этажи перекрываются. Переход между фонами делать плавным, без накопления источников.

## ФИНАЛ И ПРОЛОГ

Время финала считаем от успешной передачи всего огня, а не от первого нажатия E. В просмотренном Bonfire значения: FadeEnd 1.6, IgniteAt 2.6, RiseEnd 4.2, HopEnd 5.2 секунды. При реализации читать актуальные константы, не заводить независимый второй таймер с теми же числами.

| Момент | Аудио |
|---|---|
| 0-1.6 с | Плавно убрать окружающий звук и огонь Игни |
| 1.6-2.6 с | Секунда тишины, включая музыку и хвосты эффектов |
| 2.6 с, фактический Ignite | `bonfire_ignite`, один раз |
| 4.2 с, возвращение Игни | Вернуть петлю живого огня; `igni_respawn` только один раз, если подходит после прослушивания |
| После завершения | Не запускать звук обычной смерти, не перезапускать костёр |

Для будущего пролога использовать [таблицу таймингов 0:00-0:40](audio-elevenlabs.md#7-звуки-пролога). Фактические события монтажа важнее таймеров внутри отдельных клипов. На skip остановить все intro-источники, снять их громкостные переходы и передать звук игре один раз. INTRO-клипы не запускать сейчас автоматически на титульном экране: готового cinematic в просмотренном GameManager нет. Музыкальная шкатулка/виолончель и полный саундтрек являются отдельными музыкальными ассетами, не частью этого SFX-пакета.

## ВОРОТА

До реализации нетривиального управления состоянием добавить падающие тесты. Проверять не только наличие AudioSource, но и принятие события/число запусков через минимально наблюдаемое состояние системы. Не писать отдельный тест на каждый тривиальный slot.

1. Проверить один запуск на реальный прыжок/рывок и отсутствие запуска на отклонённое действие.
2. Проверить независимость маленькой формы и низкого топлива, отсутствие постоянного перезапуска петли у порога.
3. Проверить одну смерть, отсутствие смерти на Surrender и отсутствие накопления источников после нескольких респаунов.
4. Проверить отмену/успех удержания котла, одноразовое зажигание свечи и остановку вентилятора после его ремня.
5. Проверить однократные предупреждение/порыв за цикл, ограничение повторяющихся звуков и правильную зону после телепорта/респауна.
6. Проверить тишину финала и один запуск костра по фактической фазе Bonfire. Skip пролога проверить при его появлении; пока отметить как отложенное.
